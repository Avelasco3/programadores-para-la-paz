Sistema operativo: Es el software base que gestiona los recursos del hardware y
permite que el software (como Node.js) se ejecute.

Node.js: Es el entorno de ejecución que permite correr código JavaScript fuera
del navegador, facilitando la creación de servidores.

Aplicación server.js: Es el archivo que contiene la lógica de la API, definiendo las
rutas y cómo el servidor debe responder.

Puerto: Es un punto de entrada o comunicación lógico numerado (en este caso 3000) por 
donde el servidor recibe las peticiones.

Logs: Son registros cronológicos de la actividad del servidor, fundamentales para
monitorear errores y eventos del sistema.
